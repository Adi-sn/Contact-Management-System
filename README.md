# Contact Management System

A Python-based application for managing contacts with MySQL database integration.

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![MySQL](https://img.shields.io/badge/MySQL-8.0-orange)

## Features ✨
- **Add/Delete Contacts**: Easily manage contact entries.
- **Search Contacts**: Find contacts by name or phone number.
- **Edit Records**: Update names, numbers, or ages.
- **Bulk Operations**: Delete all contacts at once.
- **Alphabetical View**: Display contacts in sorted order.

## Prerequisites 📋
- Python 3.10+
- MySQL Server 8.0+
- `mysql-connector-python` library

## Installation 🛠️

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/contact-management-system.git
```
### 2. Install Dependencies
1. Open **Command Prompt** (Windows) or **Terminal** (Mac/Linux)
2. Run this command to install the MySQL connector:
```bash
pip install mysql-connector-python
```
## 3.How to Run in IDLE 🖥️
1. Launch **Python IDLE** from your Start Menu (Windows) or Applications folder (Mac)
2. Click **File → Open** in the IDLE menu
3. Navigate to and select the `contact.py` file
4. Press **F5** on your keyboard or click **Run → Run Module** in the menu

The program should be running now!!!
